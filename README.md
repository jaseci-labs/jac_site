# jaclang.org — the official Jac website

The marketing site for the Jac programming language, built end to end in Jac
(naturally). A single-page landing built on jac-shadcn (nova style, orange
accent, Geist) with a hand-rolled Jac syntax highlighter, an animated
node/edge/walker constellation, a self-typing terminal, and scroll-reveal
sections. Dark-first with a light-mode toggle.

## Run it

```bash
jac install        # first run: pulls npm deps
jac start          # serves on http://localhost:8000
```

`jac start --dev` for the hot-reload dev loop.

## Layout

| Path | What it is |
|---|---|
| `main.jac` | Entry: theme init + section composition |
| `components/Hero.jac` | Headline, install command, CTAs, terminal demo |
| `components/GraphBackdrop.jac` | Animated SVG topology (nodes, edges, walker pulses) |
| `components/TerminalDemo.jac` | Self-typing `jac create` → `jac start --scale` loop |
| `components/CodeBlock.jac` | Jac tokenizer + syntax-highlighted code windows |
| `components/Showcase.jac` | Tabbed language showcase (by llm / walkers / full-stack / native) |
| `components/WhyJac.jac` | Twelve notations, the grep quote, synechic + topokinetic |
| `components/Reveal.jac` | IntersectionObserver scroll reveals |
| `components/*.jac` | Remaining sections (Pillars, BuildGrid, OneBinary, Agents, Research, FinalCta, Footer) |
| `styles/site.css` | Custom layer: gradients, keyframes, token colors (safe from `jac retheme`) |
| `styles/global.css` | Generated by jac-shadcn — retheme with `jac retheme`, don't hand-edit |

Content is anchored to the monorepo README, *the twelve claims*, the
`this_is_jac` showcase, and the fundamentals book ("the ninja book").
House style: "discontinuities", not "seams"; "the first…", not "the only…".
